# techsupport
телеграмм бот сделанный для тех поддержки, отвечает на вопросы.
довольно простой. 

# инструкция
чтобы начать, надо написать команду "/start".
После этого вам покажет два вопроса, для ответа на любой их них надо 
нажать на кнопку с текстом.
Если выбрать "Я хочу узнать что это за бот", вам ответит базовой инфой про него.
Если выбрать "Мне нужна помощь техподдержки", вам задаст ещё пару вопросов,
нажмите на них чтобы получить ответ.
